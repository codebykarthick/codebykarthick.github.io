# codebykarthick.github.io

Personal portfolio site built with [Hydejack](https://hydejack.com/) Jekyll theme.

## Setup

1. Replace `assets/resume.pdf` with your actual resume
2. Edit `_data/authors.yml` to update your bio
3. Add projects in `_projects/` folder
4. Push to GitHub to deploy

## Local Development

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000

## Structure

- `_projects/` - Your project pages
- `_data/authors.yml` - Your profile info and social links
- `_config.yml` - Site configuration
- `assets/resume.pdf` - Your resume file
- `assets/img/sidebar-bg.jpg` - Background image
