# React Native Neobrutalism

A customizable Neo-Brutalism UI components library for React Native with web support.

## Overview

This library provides a collection of UI components following the neo-brutalism design aesthetic for React Native applications. The design is inspired by the work at [neobrutalism.dev](https://neobrutalism.dev).

## Status

This project is currently a **work in progress**. Documentation and usage examples will be available once the initial development is completed.

## Features

- Neo-brutalism styled components
- React Native compatibility
- Web support
- Customizable theming
