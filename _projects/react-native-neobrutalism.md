# React Native Neobrutalism

A customizable Neo-Brutalism UI components library for React Native with web support.

## About

This library provides a collection of UI components styled in the Neo-Brutalism design aesthetic - bold colors, thick borders, and strong shadows that create a raw, unpolished look.

## Tech Stack

- TypeScript
- React Native
- Web support via React Native Web
